BridgeBack AI (no API key needed)

1. pip install -r requirements.txt
2. python app.py
3. Open http://127.0.0.1:5000 in Chrome or Edge

Tabs: Translate (situations + meaning check), Voice (two-way), Readless (picture buttons),
Trip Pack (phrases + emergency numbers + offline download), Scanner (menu/signboard photo).
Translation uses the free MyMemory service (about 5,000 characters/day, 500 bytes per request).
